Session of Aug 11, 2026. Project adopted as the active workspace: experiments/linear-clone

What it is

A Linear-style project tracker: issues, OKRs, sprints, calendar, members, and an internal wiki, with Linear's dark, dense, keyboard-driven UI.

v0 is UI-first: seeded zustand store persisted to localStorage. Store actions are the future API contract.

Stack

Next.js 16 React 19 TypeScript Tailwind v4 shadcn/ui + radix zustand Clerk (optional) pnpm

pnpm dev then localhost:3000. Demo mode without Clerk keys.

House rules (from AGENTS.md and docs/)

  • Types in lib/types.ts, mutations only via lib/store.ts actions, ephemeral UI in lib/ui-store.ts
  • Routes thin; feature UI in features/<name>/. Dependency direction: app to features to components to lib
  • Design tokens and recipes from docs/DESIGN.md; no raw hex outside globals, seed, icons
  • Global dialogs and palette mount once in app/(app)/layout.tsx, driven via ui-store
  • No em or en dashes anywhere. Sentence case UI copy. Named exports, kebab-case files

Decisions

  • Backend = the .xo files themselves. No database; the app is a read-only mirror of todos.json and work-items.json
  • Seed demo data replaced entirely by real XO data; zustand action contract kept (write-back is the later seam)
  • XO root is one variable: Setup dialog override, then XO_ROOT env, then topmost ancestor with .xo
  • Clerk-to-member mapping deferred

Shipped this session

  • /api/xo/snapshot and /api/xo/folders route handlers
  • Store split into mirror slices (not persisted, resync every load) and local slices (sprints, OKRs, wiki, config)
