SHIPNOTES-COMPONENTS / DEMO NIGHT MODE

Three drop-in Web Components.

aqualang89/shipnotes-components is a small catalog of UI pieces with moving parts, built with Codex for the Ship Notes build videos on X. Each one is a single JavaScript file that defines a custom element. No npm, no build, no dependencies. The page sets attributes; the component draws, and sometimes emits an event.

Vendored unmodified at 5930afd (2026-09-26) · MIT · upstream tests Chromium only

        What they share
        
    
        One pattern, three times.
        
    
          
      
        1. One file, one tag. An IIFE defines the element behind a customElements.get() guard, so loading the script twice is harmless.
          2. 
      
        2. Shadow DOM. Styles live inside the element. Page CSS can't break it and its CSS can't leak out. Width comes from the parent.
          3. 
      
        3. Attributes in, events out. The page owns state. Changes made from code don't echo back as events.
          4. 
      
        4. Reduced motion. Each one honors prefers-reduced-motion: a static orb, an instant lamp, cards without transitions.
          5. 
      
        5. Untrusted input. Text goes in through textContent, accents must be #rrggbb and links must be http(s).
          6. 
      
        6. Made for video. A recording attribute on all three, plus renderAt(time, weights) on the orb, renders deterministic frames for the clips.
